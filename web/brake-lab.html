01 FLAT SECTION + BEND PARAMETERS

This simulator does not infer tooling, ram geometry, tonnage, backgauges or controller settings from a manufacturer name.

Bends are parallel lines across a constant-width strip. Position is measured from the left flat edge; positive/negative angle controls fold direction. Each optional obstacle is an invented 2D rectangle in the local coordinate system of the active bend. The solver uses ideal sharp hinges and a thickness-based proximity check.
